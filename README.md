# projects
Анализ рынка недвижимости Санкт-Петербурга и Ленинградской области

Описание проекта

Проект посвящён исследовательскому анализу данных (EDA) рынка жилой недвижимости Санкт-Петербурга и Ленинградской области на основе архивных данных сервиса Яндекс Недвижимость.

Цель проекта — помочь агентству недвижимости определить наиболее перспективные сегменты рынка, оценить сезонные тенденции и выявить факторы, влияющие на скорость продажи объектов недвижимости.

В рамках проекта были выполнены SQL-анализ данных, очистка выбросов, расчёт продуктовых и рыночных метрик, а также разработан аналитический дашборд в Yandex DataLens.

⸻

Цели исследования
 • Определить наиболее привлекательные сегменты недвижимости.
 • Проанализировать сроки активности объявлений.
 • Исследовать сезонность публикации объявлений.
 • Выявить факторы, влияющие на скорость продажи недвижимости.
 • Сравнить рынок Санкт-Петербурга и Ленинградской области.
 • Подготовить аналитические выводы для бизнес-решений.

Что было сделано

Очистка и подготовка данных
 • Проверка пропущенных значений и аномалий.
 • Фильтрация выбросов с использованием перцентилей.
 • Обработка аномально высоких и низких значений площади, высоты потолков, количества комнат и балконов.
 • Подготовка данных для аналитического исследования.

Исследовательский анализ данных (EDA)
 • Анализ временного периода публикации объявлений.
 • Исследование распределения объявлений по типам населённых пунктов.
 • Анализ времени активности объявлений.
 • Расчёт доли снятых с публикации объектов.
 • Анализ стоимости квадратного метра.
 • Исследование различий между Санкт-Петербургом и Ленинградской областью.

Аналитические задачи
 • Сегментация недвижимости по сроку активности объявлений.
 • Анализ влияния площади, стоимости, количества комнат и региона на скорость продажи.
 • Исследование сезонных тенденций рынка недвижимости.
 • Определение периодов повышенной активности продавцов и покупателей.

Визуализация данных
 • Разработка аналитического дашборда в Yandex DataLens.
 • Визуализация ключевых метрик и динамики рынка недвижимости.
